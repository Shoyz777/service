# Документы без юриста (веб)

Next.js + TypeScript сервис для подготовки документов исключительно по законодательству РФ:
- Хранилище шаблонов в БД (Prisma + SQLite)
- Мастер заполнения с валидацией обязательных реквизитов
- Привязка к статьям законов РФ и проверка соответствия
- AI-помощник (OpenAI, офлайн-фоллбек при отсутствии ключа)
- Черновик документа прямо в браузере
- Дисклеймер: сервис работает **только** в правовом поле Российской Федерации (другие страны появятся позже)

## Быстрый старт (локально)

### 1) Установить зависимости
```bash
npm i
```

### 2) Настроить переменные окружения
Скопируй `.env.example` в `.env`:
```bash
cp .env.example .env
```
Укажи `OPENAI_API_KEY`, чтобы включить полноценные AI-подсказки (иначе будет офлайн-фоллбек). **Не храните ключ в коде или Git — только через `.env`/секреты окружения.**

### 2.1) Как обращаться к ChatGPT API: curl или Node?
- **Node (рекомендуется для продакшена)**: стабильнее для проекта на Next.js, удобно держать токен в переменных окружения, есть ретраи и типы. Пример запроса в серверном коде (без хардкода ключа):
  ```ts
  import OpenAI from "openai";

  const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

  export async function askAI(prompt: string) {
    const response = await client.responses.create({
      model: process.env.AI_MODEL || "gpt-5-nano",
      input: [{ role: "user", content: prompt }],
      temperature: 0.2,
      max_output_tokens: 200,
    });
    return response.output_text;
  }
  ```
- **curl (подходит для тестов или CI)**: быстро проверить ключ и сетевые настройки без сборки проекта:
  ```bash
  curl https://api.openai.com/v1/responses \
    -H "Authorization: Bearer $OPENAI_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "gpt-5-nano",
      "input": [{"role":"user","content":"Привет!"}],
      "temperature": 0.2
    }'
  ```

> В обоих случаях сервис остаётся сфокусирован на праве РФ; в другие юрисдикции подсказки не распространяются.

### 3) Поднять БД и засеять шаблоны
```bash
npm run prisma:migrate
npm run seed
```

### 4) Запуск
```bash
npm run dev
```

Открой: http://localhost:3000
